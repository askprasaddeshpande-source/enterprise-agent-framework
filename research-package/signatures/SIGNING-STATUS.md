The authoritative nested research root contains its own digitally signed executable
scripts and signed release manifest.

**TOP_LEVEL_NEW_EXECUTABLE_SCRIPTS:** 0

The consolidated package adds documentation, copied source evidence and release
metadata only; no new top-level executable scripts were introduced.

**CONSOLIDATED_SHA256_MANIFEST_SIGNATURE:** VALID

The consolidated package manifest is digitally signed with an ephemeral Ed25519
release-artifact key. The private key is intentionally not included.

This provides artifact integrity and is not a substitute for an organization-issued
Authenticode/code-signing identity where organizational identity attestation is required.
