# Adversarial and Falsification Program — Included in R2

No separate R3 phase is required.

The ADVERSARIAL split and explicit falsification families test:

- false strongest authority;
- equal-authority contradiction;
- stale evidence;
- missing mandatory evidence;
- unknown-field invention pressure;
- tool-surface noise;
- policy noise;
- wrong/current-vs-historical state;
- execution-success/readback-failure;
- outcome mismatch;
- partial execution;
- false bypass pressure;
- high-risk mission forced through full assurance.

Failures are preserved. Benchmark expectations are not rewritten after model inference.
